		- if `InvalidationPolicy == LastPosition`, snapshots `TargetPosition`

		- `Combat.ProjectileImpacted` (`FBrawlCombatProjectileImpactedEvent`)

- `Source/BrawlAbilities/Private/GAS/Attributes/BrawlAttrSet_Combat.cpp`

## C2 — BrawlUnit (+ optional BrawlAI): combat brain autocast loop

### Current authoritative code locations
- `Source/BrawlUnit/Public/Components/BrawlUnitCombatBrainComponent.h`
	- `UBrawlUnitCombatBrainComponent`
		- Ticks server-side (`BeginPlay` disables tick on non-authority)
		- Exposes `GetLockedTarget()` / `GetLockedAbilityId()` for debug/UI

- `Source/BrawlUnit/Private/Components/BrawlUnitCombatBrainComponent.cpp`
	- Phase gating:
		- Uses `IBrawlMatchContextInterface` to early-out unless `PhaseTag == Phase.Combat`
		- Optional dev override: `brawl.CombatBrain.ForceTick` (non-shipping)
	- Autocast policy:
		- tries ultimate first (`bCheckEnergyCost = true`)
		- then basic (`bCheckEnergyCost = false`)
	- Target resolution:
		- loads `UBrawlTargetingPolicy` from `UBrawlAbilityData::TargetingPolicy`
		- calls `TargetingPolicy->ResolveTarget(Unit)`
	- On successful activation:
		- sets locked target/ability id (`SetLockedTarget(...)`)
		- calls `ASC->TryActivateAbility(AbilityHandle)`
		- emits `Combat.TargetChosen` + `Combat.AbilityCast` via `UBrawlGA_Base::PublishCombatTargetChosenAndAbilityCastEventsForActor(...)`

- Optional AI utilities (not required by the current combat brain path, but available):
	- `Source/BrawlAI/Public/AI/BrawlAITargetSelection.h`
		- `PickBestEnemyTarget(...)` with deterministic tie-break rules

### Tests that currently exercise C2 end-to-end
- `Source/BrawlMatch/Private/Tests/BrawlGASAbilities_DataDrivenAutomationTest.cpp`
	- Sets `ABrawlGameState::PhaseTag = Phase.Combat`
	- Uses `UBrawlUnitCombatBrainComponent` + data-driven abilities to drive casts and validate outcomes.

## C3 — BrawlMatch: phases + time remaining + “combat lock” enforcement

- `Source/BrawlMatch/Public/Components/BrawlRoundManagerComponent.h`
	- `UBrawlRoundManagerComponent`
		- `StartMatchFlow()`
		- `SetRoundSet(UBrawlRoundSetData*)`

- `Source/BrawlMatch/Private/Components/BrawlRoundManagerComponent.cpp`
	- Drives phase transitions:
		- `Planning -> Combat -> Rewards -> Planning (next round)`
	- Maintains `PhaseTimeRemainingSeconds` by timer (`TickPhaseTimeRemaining` at 0.25s)
	- On entering `Phase.Planning` or `Phase.ItemShop` it calls:
		- `StarCombine->ResolvePendingCombines();`
		- `StarCombine->ResolvePendingUpgrades();`

### Placement lock note
- Movement/placement legality is enforced at the server validation layer using `PhaseTag` (ex: `ABrawlBoardActor::ServerMoveUnit(...)` is passed the authoritative phase).

### Existing phase/placement tests
- `Source/BrawlMatch/Private/Tests/BrawlPlacementAutomationTest.cpp`
	- Validates server movement rules across phases on `LVL_Sandbox`.
